# EZTO Brand Kit

## The mark
An **E** whose middle bar becomes an **arrow breaking out of the circle**:
EZTO starts as a meme coin but moves forward, beyond the frame. The italic slant adds speed.

## Typography
**Space Grotesk** (Google Fonts): Bold for headings, Medium for body.

## Voice
- Tagline: **Vision first, hype later.**
- Display name everywhere: **EZTO | $EZTO**
- Say what EZTO *does*; never promise profit or price.

## Rules
- Only use the files in this folder: no old 3D / gold / metal logos as profile pictures.
- Don't recolor, stretch, rotate, or add effects to the mark.
- Keep clear space around the logo equal to the height of the arrow head.
