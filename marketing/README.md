Pre-launch content: introduce EZTO, push people to the website and Telegram, and warn about fake tokens.
All images are in `posts/` (1080×1350, works for Instagram feed and X).

## Rules for every post
- **Never talk about price, profit, "100x", "moon", "early = rich".** Say what EZTO *is* and *does*.
- Always point to **one place**: the website (link in bio) or Telegram.
- Repeat the safety line often: *EZTO has not launched. Any EZTO token today is not ours.*
- Same name everywhere: **EZTO | $EZTO**. Same tagline: **Vision first, hype later.**
- Hashtags: max 3–5. Use `#EZTO #Solana #crypto` plus 1–2 topic tags.
