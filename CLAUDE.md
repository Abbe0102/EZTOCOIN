# EZTOCOIN project rules

- **Everything in this repository is in English**: code, comments, docs, commit messages, PRs, website copy, assets. Never add Arabic (or any other language) to the project.
- Conversation with the founder happens in Arabic (Levantine); that is chat only, never project content.
- Brand: follow `brand/README.md` (logo files, colors, Space Grotesk, tagline "Vision first, hype later.").
- Never promise profit or price in any copy. Describe what EZTO does.
- Token code lives in `token/`; run `npm test` and `npm run typecheck` there before committing.
